# Gopherwood library

My personal copy of boot.dev's Go courses, kept for my own offline study as a paying
boot.dev member. It is not for distribution, and nothing in it is used by Gosmos.

`data/gopherwood.sqlite` is a library in Gosmos's format (version 6), together with my study
progress. Open it in Gosmos with File › Open Library…. The app and its tools live in
[jobloom/gosmos](https://github.com/jobloom/gosmos).
